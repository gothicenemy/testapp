# 🚀 Інструкція з розгортання LumenRadar AI на сервері замовника

Цей документ містить покрокову інструкцію для легкого та надійного запуску системи **LumenRadar AI** на будь-якому сервері (Linux Ubuntu/Debian, CentOS або Windows Server).

---

## ⚡ Швидкий запуск (Quick Start)

### Варіант 1: Через Docker (Рекомендовано — запуск за 1 хвилину)

Якщо на сервері встановлено **Docker** та **Docker Compose**:

1. Завантажте або схилуйте проект на сервер:
   ```bash
   git clone <URL_РЕПОЗИТОРІЮ> /opt/lumenradar
   cd /opt/lumenradar
   ```

2. Налаштуйте файл `.env` (вкажіть ключ Gemini та пошту за бажанням):
   ```bash
   cp .env.example .env
   nano .env
   ```

3. Запустіть 1-кліковий скрипт:
   ```bash
   chmod +x deploy.sh
   ./deploy.sh
   ```
   *Або вручну:*
   ```bash
   docker compose up -d --build
   ```

4. **Готово!** Відкрийте веб-панель у браузері:
   👉 **`http://IP_ВАШОГО_СЕРВЕРА:3000`**

---

### Варіант 2: Прямий запуск через Node.js (Без Docker)

Якщо на сервері встановлено **Node.js 20+**:

1. Перейдіть до папки проекту:
   ```bash
   cd /opt/lumenradar
   ```

2. Встановіть залежності та скомпілюйте проект:
   ```bash
   npm install
   npm run build
   ```

3. Запустіть сервер під менеджером процесів **PM2** (для автоперезапуску):
   ```bash
   npm install -g pm2
   pm2 start "npm start" --name "lumenradar"
   pm2 save
   pm2 startup
   ```

   *Або простий фоновий запуск:*
   ```bash
   nohup npm start > lumenradar.log 2>&1 &
   ```

4. Панель доступна за адресою: **`http://IP_ВАШОГО_СЕРВЕРА:3000`**

## ⚙️ Налаштування файлу `.env`

Всі ключові параметри керуються через файл `.env` в корені проекту або безпосередньо через веб-інтерфейс (вкладка «Керування та CLI»):

```env
# 1. Штучний Інтелект Google Gemini
# Отримайте безкоштовний ключ: https://aistudio.google.com/apikey
GEMINI_API_KEY="AIzaSy..."
GEMINI_MODEL="gemini-2.5-pro"

# 2. Отримувач Email-дайджесту (можна змінювати в UI в 1 клік)
DIGEST_RECIPIENT="director@company.ua"

# 3. SMTP Поштовий сервер для відправки
# Якщо пароль не вказано — система працює в режимі безпечної симуляції (демо)
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=587
SMTP_SENDER="digest@company.ua"
SMTP_USER="digest@company.ua"
SMTP_PASSWORD="app-password-here"

# 4. Мережевий порт
PORT=3000
API_PORT=3000
TZ=Europe/Kyiv
```

## 📧 Робота з Email-дайджестом

1. У веб-інтерфейсі відкрийте вкладку **«Email-дайджест (HTML)»**.
2. Введіть або відредагуйте адресу електронної пошти отримувача прямо в полі вводу.
3. Оберіть кількість пропозицій: **«Топ-20 інновацій»**, **«Топ-10»** або **«Всі моделі»**.
4. Натисніть кнопку **«Надіслати дайджест на пошту»** або **«Тестовий лист»**.
5. Результат та історія зберігаються в таблиці `digests` бази даних.

---

## 🤖 Підключення Gemini API Key

1. Отримайте безкоштовний ключ у [Google AI Studio](https://aistudio.google.com/apikey).
2. Відкрийте вкладку **«Керування та CLI»** у веб-інтерфейсі.
3. Введіть ключ у поле «Google Gemini API Key» та натисніть **«Перевірити та зберегти»**.
4. Система миттєво проведе пінґ-тест моделі `gemini-2.5-pro` та увімкне AI-екстракцію для нових світильників.

## 🛡️ Корисні команди для адміністратора

| Команда | Опис |
|---|---|
| `docker compose ps` | Переглянути статус контейнерів |
| `docker compose logs -f` | Переглянути живі логи обходу каталогів |
| `docker compose restart` | Перезапустити всі сервіси |
| `npm run test:compliance` | Запустити автоматичну верифікацію 18 тестів ТЗ |
| `npx tsx backend/main.ts run` | Запустити сканування всіх 20 брендів вручну |
