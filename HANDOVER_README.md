# LumenRadar AI — Посібник передачі та розгортання для замовника (Handover Guide)

## 1. Загальний опис системи
**LumenRadar AI** — автономна корпоративна система моніторингу продуктових новинок 20 провідних європейських виробників освітлення відповідно до Технічного Завдання v1.0.

Система функціонує в повністю автоматичному режимі:
- **Періодичність:** Кожні 14 днів (понеділок, 09:00 Europe/Kyiv) за замовчуванням.
- **Охоплення:** 20 європейських брендів (ERCO, Zumtobel, Trilux, Targetti, iGuzzini, Fagerhult, XAL, Delta Light, Flos, Artemide, BEGA, Regent, Molto Luce, RZB, Thorlux, Thorn, SLV, Wever & Ducré, Modular Lighting, Luceplan).
- **AI-обробка:** Вилучення характеристик (20+ параметрів), відсікання маркетингового шуму та формування професійного резюме українською мовою з 5 пунктів (FR-25).
- **Email-дайджест:** Адаптивний мобільний HTML-лист (до 20 ключових моделей ринку, по 1 найкращій від бренду) з прямими верифікованими посиланнями на сторінки моделей без помилок 404.
- **База даних:** 5 реляційних таблиць (FR-39) у SQLite / PostgreSQL у режимі WAL.

---

## 2. Системні вимоги
- **Сервер:** Будь-який Linux (Ubuntu 20.04/22.04/24.04, Debian 11/12), CentOS/RHEL, або Windows Server.
- **Ресурси:** Мінімум 1 vCPU, 1 GB RAM, 2 GB дискового простору.
- **Мережа:** Доступ до інтернету (HTTP/HTTPS) для моніторингу каталогів і викликів Gemini API.
- **Програмне забезпечення (один з варіантів):**
  - **Варіант 1 (Рекомендовано):** Docker 20.10+ та Docker Compose v2+.
  - **Варіант 2:** Node.js 20.x або 22.x LTS (npm 10+).

## 3. Швидкий старт у 3 кроки

### Крок 1. Розпакуйте архів на сервері
```bash
unzip lumenradar-deploy.zip -d /opt/lumenradar
cd /opt/lumenradar
```

### Крок 2. Налаштуйте конфігурацію (.env)
Відкрийте або відредагуйте файл `.env`:
```ini
# Google Gemini API (отримати безкоштовно на https://aistudio.google.com/)
GEMINI_API_KEY="AIzaSy..."
GEMINI_MODEL="gemini-3.8-flash"

# Email для отримання дайджесту
DIGEST_RECIPIENT="client@your-company.com"

# SMTP налаштування для реальної розсилки
SMTP_HOST="smtp.gmail.com"
SMTP_PORT=587
SMTP_SECURE=false
SMTP_SENDER="digest@lighting-monitor.com"
SMTP_USER="your-email@gmail.com"
SMTP_PASSWORD="your-app-password"

# Порт веб-інтерфейсу
PORT=3000
API_PORT=3000
TZ=Europe/Kyiv
```
*(Примітка: якщо SMTP-пароль не вказано, система автоматично працює в безпечному симуляційному режимі, генерує файл .eml та логує успішне формування).*

### Крок 3. Запустіть проєкт

#### Сценарій А: Через Docker (1 команда)
```bash
./deploy.sh
# або безпосередньо:
docker compose up -d --build
```

#### Сценарій Б: Без Docker (прямий запуск Node.js)
```bash
npm install
npm run build
npm start
```
*(Для постійної фонової роботи на Linux без Docker можна використати `pm2 start "npx tsx backend/server.ts" --name lumenradar`).*

#### Сценарій В: На Windows Server
Двічі клікніть `deploy.bat` або виконайте у PowerShell:
```powershell
.\deploy.bat
```

## 4. Доступ до панелі керування
Після запуску перейдіть у веб-браузері за адресою:
```
http://<IP_АДРЕСА_СЕРВЕРА>:3000
```
- Якщо запуск здійснюється локально: `http://localhost:3000`

### Основні розділи інтерфейсу:
1. **📊 Огляд ринку:** Загальна статистика моніторингу, графік динаміки та картки 20 верифікованих моделей із прямими посиланнями.
2. **🏢 20 брендів:** Реєстр виробників з інформацією про спеціалізацію, стан сайтів та наявність sitemap.xml.
3. **🗄️ База даних:** Інспектор 5 реляційних таблиць (`products`, `manufacturers`, `crawl_runs`, `pages`, `digests`).
4. **📧 Email-дайджест:** Перегляд адаптивного HTML-дайджесту, миттєве редагування адреси отримувача, ручна відправка листа кнопкою «Надіслати зараз» та завантаження `.eml`.
5. **🛡️ Аудит ТЗ:** Інтерактивний чек-лист 60 вимог ТЗ з результатами проходження 18 тест-кейсів.
6. **⚙️ Система:** Налаштування та онлайн-тестування ключа Gemini API, керування параметрами SMTP, перегляд живих системних логів у реальному часі.

## 5. Безпека та ізоляція помилок (FR-54..FR-58)
- **Ізоляція збоїв (FR-54):** Помилка чи блокування одного сайту (WAF/Cloudflare) не зупиняє моніторинг інших 19 виробників.
- **Аномалії (FR-56):** Автоматичний алертинг, якщо кількість знайдених сторінок різко падає більш ніж на 70%.
- **Маскування секретів (FR-58):** Жоден API-ключ або пароль SMTP ніколи не записується у відкритому вигляді в системні логи.
- **Канонікалізація та дедуплікація (FR-13, FR-29):** Автоматичне видалення UTM-міток, нормалізація шляхів та унеможливлення дублювання товарів між мовними версіями.
