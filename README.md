# 💡 LumenRadar AI — AI-система моніторингу новинок європейських виробників освітлення

> **Версія:** 1.0 (Повна відповідність Технічному завданню v1.0 від 31.08.2026)  
> **Стек:** Node.js (TypeScript) + Google Gemini 2.5 Pro + SQLite (WAL mode) / PostgreSQL 16 + Cheerio / Fast-XML + Nodemailer + React 19 / Vite / Tailwind CSS

---

## 📌 Огляд системи

**LumenRadar AI** — корпоративна система інтелектуального моніторингу ринку освітлення. Кожні 14 днів система автоматично:
1. Опитує каталоги, новинні розділи та `sitemap.xml` **20 провідних європейських виробників** освітлення.
2. Виявляє нові світильники та продуктові серії через алгоритми Diff SHA-256 та нормалізацію canonical URL.
3. Використовує **Google Gemini 2.5 Pro** для екстракції технічних характеристик (потужність, світловий потік, світловіддача, CRI, UGR, IP, протоколи керування) **без галюцинацій** (FR-23).
4. Здійснює багатофакторну дедуплікацію та розраховує індекс інноваційності (*Relevance Score*).
5. Формує та розсилає адаптивний україномовний **HTML-дайджест Топ-20 ключових новинок** на електронну пошту замовника.

## 🚀 Швидке розгортання на сервері замовника

### Варіант 1: Через Docker (1 команда)
```bash
# 1. Запуск за 1 хвилину
docker compose up -d --build

# 2. Відкрийте панель у браузері:
# http://IP_СЕРВЕРА:3000
```

### Варіант 2: Прямий запуск через Node.js (v20+)
```bash
# Встановлення та запуск
npm install
npm run build
npm start
# Доступно на: http://localhost:3000 або http://localhost:3001
```

Детальні інструкції для Ubuntu, Debian, CentOS та Windows Server дивіться у файлі **`DEPLOY.md`**.

## 🗄️ Реляційне сховище (5 Таблиць за FR-39)

1. **`manufacturers`**: 20 брендів, домени, посилання на каталоги, sitemaps, прапорець `is_js_rendered`.
2. **`crawl_runs`**: сесії сканування, статус, кількість перевірених сторінок, підтверджених новинок, журнал помилок.
3. **`pages`**: виявлені URL-адреси, SHA-256 хеші контенту, мітки часу виявлення.
4. **`products`**: підтверджені моделі світильників, характеристики в JSON (power_w, flux, efficacy, CRI, IP, control), українське резюме, прямі посилання на офіційні сторінки, 16-значний детермінований MD5 хеш.
5. **`digests`** (+ `digest_items`): журнал сформованих дайджестів, статус відправки SMTP, адреса отримувача, HTML-вміст.

## 📧 Робота з Email-дайджестом

- **Обмеження моделей:** Дайджест оптимізовано під **Топ-20 інновацій** (найбільш енергоефективні та технологічні моделі). Можна перемикати на «Топ-10» або «Всі моделі».
- **Редагування пошти:** Адресу отримувача можна змінювати безпосередньо у веб-панелі (вкладка «Email-дайджест») або через файл `.env` (`DIGEST_RECIPIENT`).
- **Відправка в 1 клік:** Кнопка «Надіслати дайджест на пошту» генерує лист і передає його через поштовий сервер або симулює відправку, якщо пароль SMTP не вказано.

## 🤖 Підключення Google Gemini AI

1. Отримайте безкоштовний ключ у [Google AI Studio](https://aistudio.google.com/apikey).
2. Відкрийте вкладку **«Керування та CLI»** в інтерфейсі.
3. Введіть ключ у поле «Google Gemini API Key» та натисніть **«Зберегти ключ»**.
4. Натисніть **«Перевірити»** для миттєвого тесту зв'язку з моделлю `gemini-2.5-pro`.
5. Якщо ключ не вказано, система автоматично працює на безпечному евристичному DOM-парсері із захистом від галюцинацій (FR-23).

- ✓ Виявлення нових моделей із прямими URL

- ✓ Дедуплікація мовних версій EN / DE
- ✓ Захист зв'язку при зміні URL через MD5-хеш
- ✓ Ізоляція збоїв 500 (FR-54)
- ✓ Відсутність галюцинацій у специфікаціях (null для відсутніх даних)
